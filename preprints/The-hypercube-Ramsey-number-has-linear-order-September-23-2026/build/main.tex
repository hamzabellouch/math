\begin{abstract}
We prove that the two-color Ramsey number of the $n$-dimensional binary cube
is at most $C2^n$, where $C$ is an absolute constant. This resolves positively
the hypercube Ramsey conjecture of Burr and Erd\H{o}s.
\end{abstract}
