\textbf{Summary. Stated improvement; optimal complexity open}

\hypertarget{question}{%
\subsection{Question}\label{question}}

How many independently deleted copies of an unknown binary string suffice to reconstruct every length-n string?

\hypertarget{result}{%
\subsection{Result}\label{result}}

For retention probability \(p\), an upper bound \(\exp(O(p^{-1}(\log n)^3(1+\log\log(2n))^6))\) on the number of traces. The report also gives a polynomial sample bound when deletion probability is at most \(n^{-\varepsilon}\) for fixed \(\varepsilon>0\).

\hypertarget{scope-and-remaining-questions}{%
\subsection{Scope and remaining questions}\label{scope-and-remaining-questions}}

Provides the requested improved sample upper bound. It does not prove matching optimality or polynomial reconstruction running time.
